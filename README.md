# LocalLife-Go

基于 **Go、CloudWeGo Hertz、GORM、MySQL 和 Redis** 的本地生活服务后端，采用模块化单体架构，围绕用户、商户、探店内容、关注动态和优惠券构建业务模块。

> 当前处于基础框架阶段，业务功能正在逐步开发。

## 技术框架

| 技术 | 用途 |
| --- | --- |
| Go | 服务端开发语言 |
| CloudWeGo Hertz | HTTP 服务、路由和中间件 |
| GORM | 数据库访问 |
| MySQL | 业务数据持久化、事务与数据约束 |
| Redis | 会话、缓存、地理位置索引与异步处理的基础设施 |
| golang-migrate | 版本化 SQL 数据库迁移 |
| slog | 结构化访问日志 |
| Docker Compose | 本地开发与集成测试依赖编排 |

## 架构设计

采用模块化单体设计，业务模块按以下职责分层：

- **Handler**：请求解析、参数校验和响应映射。
- **Service**：业务规则、事务边界与缓存协调。
- **Repository**：数据持久化与查询。
- **Middleware**：请求标识、超时控制、异常恢复与访问日志。

MySQL 作为业务数据的权威来源，Redis 承载缓存与辅助索引。请求通过 `context.Context` 传递上下文和超时，连接池由应用统一管理。

当前已搭建 HTTP 与基础设施层，业务分层随各模块逐步实现。

## 已实现功能

- **配置管理**：环境变量加载、类型解析与参数校验。
- **HTTP 服务**：Hertz 路由、统一 JSON 响应与错误分类。
- **请求处理**：Request ID、上下文超时、异常恢复和结构化访问日志。
- **依赖连接**：MySQL / Redis 连接池、启动连通性检查与资源释放。
- **健康检查**：`GET /healthz` 检查服务存活，`GET /readyz` 检查依赖可用性。
- **生命周期管理**：启动错误处理、信号响应与优雅退出。
- **数据库迁移**：用户、商户类型、商户、探店内容、关注关系、优惠券、秒杀库存和订单的初始表结构，包含订单唯一约束与库存非负约束。
- **测试支持**：配置、错误映射、HTTP 和生命周期测试，以及真实 MySQL / Redis 集成测试用例。
